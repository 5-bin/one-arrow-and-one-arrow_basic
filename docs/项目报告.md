# 一箭又一箭项目报告

## 1 项目概述

本项目完成了一款基于 Python 和 Pygame 的桌面益智游戏“一箭又一箭”。游戏以 7×8 棋盘为载体：每个格子中可放置一支指定方向的箭头，玩家只有在箭头指向的路径上没有其他未消除箭头时，才能使该箭头飞出棋盘。项目围绕“规则判断准确、交互反馈及时、关卡可验证、代码易维护”四个目标实现了完整的可玩版本，并完成了桌面程序打包。

## 3 设计说明

### 3.1 游戏流程

程序由开始界面进入关卡选择或直接开始游戏。进入关卡后，玩家反复选择可飞出的箭头；每一次合法操作会触发飞出动画并增加分数，非法操作会触发红色晃动和失误扣减。棋盘清空后显示通关结算并允许进入下一关；失误次数归零后显示失败结算并可重新开始。完成第 6 关后显示全部通关页面。

游戏运行过程使用明确的状态划分：开始、关卡选择、游戏中、箭头飞行、通关、失败和全部通关。飞行动画、阻挡反馈和弹窗出现时会限制不适当的重复操作，避免出现同一箭头被重复删除或失误被重复扣除的问题。

### 3.2 核心算法

阻挡判断由 `is_blocked` 完成。算法从待判断箭头的下一格开始，沿箭头方向逐格检查直到越过棋盘边界；只要遇到一个未消除的箭头即判定为被阻挡，否则可飞出。该逻辑不依赖箭头在列表中的顺序，且已消除箭头不会继续阻挡路径。

自动求解由 `solve_level` 实现。算法使用深度优先搜索和回溯枚举当前可飞出的箭头，使用“剩余箭头位掩码”表示搜索状态，并以已访问状态集合去除重复分支。求解器设有节点上限，在复杂或异常关卡中会主动停止并返回友好提示，避免界面长时间无响应。搜索过程基于深拷贝数据进行，不会污染实际游戏中的关卡配置与箭头状态。

### 3.3 模块划分

| 模块 | 职责 |
| --- | --- |
| `main.py` | 程序入口，启动游戏；同时导出核心对象以方便自动化测试 |
| `config.py` | 集中定义窗口、棋盘、颜色、计分规则、星级阈值和关卡数据 |
| `game_runner.py` | 管理 Pygame 主循环、页面状态、事件响应、动画和界面编排 |
| `game_logic.py` | 提供与 Pygame 无关的规则判断、关卡复制、提示、评分和 DFS 求解 |
| `rendering.py` | 负责中文字体、棋盘、箭头、按钮和弹窗的绘制 |
| `audio.py` | 加载、播放和开关本地音效；在无音频设备时自动降级而不影响游戏运行 |

这种划分将纯规则逻辑从图形界面中分离出来，使关卡可解性、评分和阻挡判断能够在不启动窗口的情况下测试；关卡与界面常量集中配置，也便于后续新增关卡或调整数值。

## 4 关键功能说明

### 4.1 关卡与难度

项目共设置 6 个预设关卡，箭头数量由少到多递增。前几关帮助玩家理解“先清除路径末端箭头”的规则；中间关卡引入多条相互独立或相互影响的箭头链；最后一关使用完整的 7×8 棋盘，要求玩家根据从外向内逐层解锁的关系完成清除。每关配置独立的初始失误次数，难度越高，容错越低。

### 4.2 交互与反馈

可点击箭头沿方向飞出棋盘；不可点击箭头会以约 0.3 秒的红色晃动给出反馈。界面提供重新开始、提示、返回菜单、自动求解和声音开关；返回菜单与退出操作通过确认弹窗防止误触。所有关卡重置统一经过加载函数，保证旧的飞行、偏移和提示状态不会遗留到新一局。

### 4.3 容错设计

中文字体按系统路径和字体匹配顺序尝试加载，降低中文显示为乱码或方块的概率。音频初始化和单个音效加载均采用异常处理；没有音频设备或个别资源读取失败时，游戏仍可正常运行。自动求解限制箭头数和搜索节点数，避免非预期数据导致长时间搜索。

## 5 测试与验证

项目编写了 19 项纯逻辑自动化测试，执行命令如下：

```bash
./.venv/bin/python -m unittest discover -s tests -v
```

本次整理时，上述测试全部通过。测试覆盖内容包括：

- 四个方向的路径阻挡判断、列表顺序无关性及已消除箭头不阻挡；
- 边缘朝外箭头的安全性；
- 6 个预设关卡均存在完整清关顺序，最后一关恰好填满棋盘；
- 重开后产生独立、无动画残留的箭头副本；
- DFS 求解的正确性、无解场景、状态不污染和搜索上限；
- 提示只返回当前可飞箭头；
- 三星、二星和一星的评分阈值。

人工界面测试记录表位于 `tests/TEST_RECORD_TEMPLATE.md`，覆盖正常飞出、被阻挡反馈、通关跳转、失败重开、动画期间点击和最后一关结算等实际操作场景。

## 6 运行与交付

源码运行方式：

```bash
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
./.venv/bin/python main.py
```

项目同时提供 PyInstaller 生成的 macOS 应用 `dist/一箭又一箭.app`，以及命令行发布目录 `dist/一箭又一箭/`。音效资源保存在 `assets/sounds/`，其来源和许可说明已随项目保留。

## 7 总结与后续改进

本项目完成了从规则实现、关卡设计、图形交互、音效反馈、自动求解、自动化测试到桌面打包的完整开发闭环。当前版本适合作为单机益智游戏课程作业的交付成果。

后续可考虑加入关卡进度持久化、自定义关卡编辑器、更丰富的箭头类型、撤销操作、排行榜或更细粒度的关卡难度数据，以提升长期可玩性与扩展性。
