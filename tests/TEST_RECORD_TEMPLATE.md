## 三关完整通关回归清单

- 第 1 关：`(3, 5) → (3, 1) → (6, 7)`。
- 第 2 关：`(6, 3) → (1, 3) → (4, 7)`。
- 第 3 关：`(0, 4) → (2, 4) → (5, 1) → (5, 5) → (6, 7)`。

## 已知边界检查建议

- 飞行时持续快速点击棋盘：应无重复删除、无崩溃；动画结束后才允许下一次箭头操作。
- 晃动的 0.3 秒内点击其他箭头：应不产生额外扣失误或删除。
- 最后一关最后一箭飞出：应直接进入“全部通关”，而非显示不可用的“下一关”按钮。
- 当前代码的“重新开始”按钮仅在 `PLAYING` 状态响应；飞行 (`FLYING`) 时不会响应。若需求要求动画中也能重开，建议将重开按钮事件从 `state == GameState.PLAYING` 放宽到 `(PLAYING, FLYING)`，并调用既有 `load_level(level_index)` 清空飞行动画引用。
